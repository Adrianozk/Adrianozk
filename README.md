## Projetos em destaque

### [SuaLuz InfluxDB Importer](https://github.com/Adrianozk/sualuz-influxdb-importer)

Pipeline de Engenharia de Dados em Python que extrai telemetria de consumo de energia da plataforma SuaLuz, normaliza os registros e os grava no InfluxDB para análise no Grafana.

O projeto inclui validação do contrato da API, tratamento de timestamps, escrita idempotente, modo `dry-run`, testes automatizados e integração contínua com GitHub Actions. A aplicação também é executada em container no meu homelab, com publicação automatizada de imagem e deploy gerenciado pelo Portainer.

**Stack:** Python · InfluxDB · Grafana · Docker · GitHub Actions · Pytest

### [Linux Server IP Notification](https://github.com/Adrianozk/linux-server-ip-notification)

Automação em Shell Script que detecta mudanças no IP público de um servidor Linux e envia notificações pelo Discord, criada para resolver uma necessidade real de operação do meu homelab.

**Stack:** Shell Script · Linux · Discord Webhooks · Automação
